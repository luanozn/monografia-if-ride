\chapter{Análise e Projeto do Sistema}

Este capítulo detalha a fase de análise e projeto do IF Ride, demonstrando os objetivos estratégicos e metodologia experimental em uma estrutura técnica formalizada. O propósito central desta etapa é delimitar o escopo funcional e as restrições de negócio que asseguram a viabilidade do software proposto.

A estruturação do capítulo é fundamentada na identificação das necessidades dos usuários e nas regras de negócio que regem o compartilhamento de caronas no contexto acadêmico. Para isso, o conteúdo é separado em:

\begin{itemize}
    \item \textbf{Levantamento de Requisitos}: Especificação das capacidades funcionais e não funcionais do sistema.
    \item \textbf{Regras de Negócio}: Formalização das restrições lógicas que garantem a integridade do sistema e independem de tecnologia.
    \item \textbf{Modelagem do Sistema}: Representação abstrata da solução, incluindo diagramas essenciais e modelagem de dados.
\end{itemize}

\section{Levantamento de Requisitos}

O levantamento de requisitos é a base de todo o desenvolvimento do projeto, sendo a fase de maior importância, visando detalhar desde os casos mais básicos, até as regras mais complexas que devem ser implementadas com o objetivo de garantir o acesso e resolução dos principais problemas que os usuários poderiam enfrentar durante a utilização do IF Ride.
